# Estandares de codificacion usados (Java)

| Elemento    | Regla                                | Ejemplo                        |
|-------------|--------------------------------------|--------------------------------|
| Paquetes    | minusculas, sin guiones bajos        | `co.edu.sena.mortalidad.dao`   |
| Clases      | PascalCase, sustantivos              | `RegistroMortalidad`           |
| Metodos     | camelCase, empiezan con verbo        | `consultarPorId`, `insertar`   |
| Variables   | camelCase, nombres descriptivos      | `avesMuertas`, `registro`      |
| Constantes  | MAYUSCULAS_CON_GUION_BAJO            | `MAX_GALPONES`, `SQL_INSERTAR` |
| Comentarios | Javadoc en clases y metodos publicos | `/** ... */`                   |
